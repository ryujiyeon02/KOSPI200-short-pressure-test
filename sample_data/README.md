# 합성 샘플 데이터

원본은 FnGuide DataGuide에서 받은 `3주차 데이터 원본.xlsx`(시트: 종가, 수정주가, 시가총액, 코스피200구성여부, 대차거래잔고수량, 차입공매도잔고수량)이며 공개하지 않습니다. 이 폴더의 CSV는 각 시트의 논리 구조를 보여주는 **가짜 값**이고 결과 산출에 쓰지 않았습니다.

```bash
python scripts/generate_sample_data.py
```

| 샘플 | 원본 시트 | 비고 |
| --- | --- | --- |
| `종가_sample.csv` | 종가 (수정 전 원종가) | 상장주식수 역산 분모에 사용 |
| `수정주가_sample.csv` | 수정주가 | 다음 달 수익률 |
| `시가총액_백만원_sample.csv` | 시가총액 | 백만원 단위 → 주식수 역산 시 ×10⁶ |
| `코스피200구성여부_sample.csv` | 코스피200구성여부 | Y/N |
| `대차거래잔고수량_sample.csv` | 대차거래잔고수량 | 주 프록시, 전 종목 관측 |
| `차입공매도잔고수량_sample.csv` | 차입공매도잔고수량 | 보조 프록시, 공시 임계값 이상만 보고(나머지 결측) |

실제 원본 시트는 9행에 코드, 10행에 종목명, 15행부터 날짜별 값이 있는 DataGuide 형식입니다(`src/short_pressure_analysis.py`의 `read_wide_sheet`).
